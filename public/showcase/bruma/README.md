# Bruma design showcase

Bruma is a fictional identity and illustrative content, not a customer case study.

Design reference: LANIN's editorial split hero and two-column menu, `apps/sitios/modelos/brooklyn/components/sections/{hero,menu}.tsx`, source revision `dd4034ae0f9530a7716abfd4ce1d716f5c9fa15f`. Source MIT notice is retained in `LICENSE.txt`. Implementation was adapted for this portfolio's Next 16/Tailwind 3 stack; no LANIN runtime, database, contact details, fonts, photographs, branding, testimonials or business data were imported.

Asset inventory: `cafe.svg` is an original local vector illustration authored for this showcase; no third-party image/font download. Display serif uses the browser's Georgia fallback; shell uses existing portfolio fonts.

Verified capability scope: static responsive content, in-page menu navigation and native FAQ disclosure. Contact, reservations, commerce, loyalty, backend and payment processing are not implemented or represented as included. The demo links back to packages but never selects one or initiates a purchase. Localized routes: `/demo/es/bruma`, `/demo/en/bruma`; route metadata declares noindex/nofollow.
