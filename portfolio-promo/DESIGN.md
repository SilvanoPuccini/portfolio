# Design System — Silvano Puccini Portfolio

## Palette

| Role       | Value   | Usage                          |
| ---------- | ------- | ------------------------------ |
| Background | #0f0f14 | All scenes, consistent canvas  |
| Foreground | #f0f0f0 | Headlines, primary text        |
| Secondary  | #aaaaaa | Labels, metadata, subtitles    |
| Accent     | #00d4d4 | Highlights, lines, key numbers |

## Typography

| Role     | Family         | Weight | Usage               |
| -------- | -------------- | ------ | ------------------- |
| Display  | Space Grotesk  | 700    | Headlines, titles   |
| Mono     | JetBrains Mono | 400    | Tags, code, labels  |

## Mood

Minimal, dark, editorial. No noise, no gradients. Clean geometry. Cian as surgical accent — not decorative glow. Confidence without flash.

## Do's

- Use cian (#00d4d4) sparingly for maximum impact
- Anchor content to edges, not centered-floating
- Structural dividers and hairline rules
- Tabular nums on all stat values

## Don'ts

- No gradient text
- No neon glow effects
- No rounded pill shapes on cards
- No decorative opacity below 10%
